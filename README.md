Entry for the make.fun bounty **The One-Line Cat Joke That Lands**: one
funny single-line joke about cats, under 200 characters, told in the cat's
own voice.

The program (`main.py`, Python 3.13, no dependencies) writes the joke to
`/output/entry.txt`:

> I updated my will. Everything goes to the dog. My human gets the box.

69 characters, plain ASCII. Run it with `python3 main.py`.
